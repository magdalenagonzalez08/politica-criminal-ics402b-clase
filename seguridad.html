Acceso del grupo

Política de acceso y seguridad

Esta página explica cómo funciona el acceso y qué límites tiene. Está pensada para un grupo de estudio, no para datos sensibles.

Qué protege

El acceso pide un usuario y una clave para que el enlace no quede abierto a cualquier persona que lo reciba. Es un filtro básico para el grupo.

Cómo se guardan las claves

No se guardan claves en texto plano dentro del sitio. Cada usuario tiene una sal distinta y su clave se verifica con PBKDF2-SHA-256 y 210.000 iteraciones.

Sesión

La sesión dura 8 horas y se guarda en la pestaña actual. Al cerrar el navegador se pierde. El botón Salir del menú lateral cierra la sesión de inmediato.

Intentos

Después de 5 intentos fallidos, el usuario se bloquea durante 5 minutos. Esto frena pruebas automáticas simples, aunque no sustituye un servidor de autenticación.

Qué no debes compartir

No compartas tu usuario, tu clave ni capturas con la sesión abierta. Si compartes el enlace, la otra persona verá la pantalla de acceso, pero no entrará sin una clave válida.

Límite importante

GitHub Pages es un sitio estático. Aunque el acceso funciona como filtro, una persona con conocimientos técnicos podría inspeccionar los archivos públicos del sitio. No lo uses para información confidencial ni para cobros. Para autenticación real hace falta un servicio con servidor, como Supabase.

Datos y privacidad

El sitio no pide correo, teléfono ni datos personales. El avance de estudio se guarda solo en el navegador de cada persona con localStorage. No hay analítica ni rastreadores.

Si una clave se filtra

Hay que generar una clave nueva y actualizar el archivo de usuarios. Mientras tanto, esa clave debe dejar de usarse.
